# AgroVision AI

A Vite + React + TypeScript website concept for tomato-leaf education and image-analysis demonstrations.

## Run locally

Prerequisites: Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:3000`).

## Build locally

```bash
npm run build
npm run preview
```

Vite writes the production site to `dist/`. **Do not publish the repository source files directly as a static website.** Publish the built `dist/` output.

## Deploy to GitHub Pages

A workflow is included at `.github/workflows/deploy.yml`.

1. Push this project to the repository's `main` branch.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **GitHub Actions**.
4. Open the repository's **Actions** tab and wait for the `Deploy AgroVision AI to GitHub Pages` workflow to finish successfully.
5. Open the Pages URL shown in **Settings → Pages**.

The workflow builds the Vite app and publishes only the `dist/` folder. The Vite base path is configured as `./` so built files can load from a GitHub Pages project URL.

## Important: current classifier limitation

The current `src/services/diseaseClassifier.ts` is a demonstration heuristic based on pixel-color ratios. It is **not** a trained machine-learning model and does not load ONNX weights. Its displayed confidence values and some lesion indicators are generated by demo logic. Do not describe its output as a validated AI diagnosis or use its confidence as an accuracy claim.

To provide real model inference, integrate the actual trained model and its verified preprocessing/output mapping, and remove unsupported accuracy claims from the interface.

## Environment variables

`.env.example` is only a template. Never commit real API keys or secrets. This frontend currently does not contain a functioning Gemini assistant integration.
